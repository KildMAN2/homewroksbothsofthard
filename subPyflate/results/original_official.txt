Interpretation:
- The Python interpreter dispatch loop `_PyEval_EvalFrameDefault`
  dominates, consistent with the pure-Python decompressor: every symbol
  the Huffman decoder emits goes through it.
- Debug-allocator overhead (`_PyMem_DebugCheckAddress`, `_PyMem_DebugRawFree`)
  is visible because python3-dbg turns on extra memory-safety checks;
  these disappear under a release build.
- The measured wall clock (1257 s) reflects TCG's software emulation
  slowdown (~15-20x vs native). Comparisons vs the FINAL run are still
  meaningful because both used the identical TCG environment.

Hardware counters status:
- Not supported under TCG (also not supported under Windows/WHPX per
  the raytrace team's own note in Project/RUN_JAMMY_LOCAL.md). See
  docs/03_profiling.md for the explicit documentation of this
  environment limit.
